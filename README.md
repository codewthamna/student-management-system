# Student Management System (C++)

## 📌 About the Project
This is a **console-based Student Management System** developed in **C++**.  
The program allows users to manage student records using a **menu-driven interface**, making it suitable for practicing **basic data management and program logic**.

The system stores student details such as name, roll number, course, class, and contact information using arrays and provides full **CRUD functionality**.

---

## 🛠️ Technologies Used
- C++
- Arrays
- Functions
- Conditional Statements
- Loops
- Console Input/Output

---

## ✨ Features
- Add multiple student records  
- Display all stored student records  
- Search a student by roll number  
- Update existing student information  
- Delete a specific student record  
- Delete all student records  
- Simple and interactive menu-driven system  

---

## ⚙️ How the Program Works
1. The user is presented with a menu of options.
2. The user can choose to add, view, search, update, or delete student records.
3. Student data is stored in parallel arrays during program execution.
4. Records are identified uniquely using **roll numbers**.
5. The program continues running until the user chooses to exit.
